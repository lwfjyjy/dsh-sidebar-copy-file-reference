# DSH 插件：复制文件行号引用

DeepSeek Harness 插件：在**右侧文件预览**里选中或点击代码行，一键复制 / 插入形如
`@src/main/java/.../LogAspect.java#L92-L94` 的文件引用。

## 功能

- **单击某行**：自动选中该行并复制 `@相对路径#L92`
- **拖选多行**：自动复制 `@相对路径#L92-L94`
- **代码区右上角悬浮工具栏**（纯图标按钮，悬停显示提示；切换代码行时重播进场动画，从右侧淡入、向左淡出）
  - 复制图标：写入剪贴板；图标从「拷贝」形变成「钩子」
  - 左箭头图标：插入当前会话输入框；图标从「左箭头」形变成「钩子」
  - 右上角「×」：关闭工具栏，下次选中/点击代码行时会再次出现
- 路径按**工作区根目录**计算

## 安装（DeepSeek Harness）

### 推荐：从 GitHub 安装

1. 打开左侧 **插件（Plugins）** 页面
2. 右上角点 **「+ 添加插件」**
3. 在输入框粘贴：`https://github.com/lwfjyjy/dsh-sidebar-copy-file-reference`
4. 点 **「安装」**，完成后点 **「立即启用」**
5. ⚠️ **完全退出并重新打开** DeepSeek Harness（不是只刷新）

> 想锁定某个版本，可改填：
> `git+https://github.com/lwfjyjy/dsh-sidebar-copy-file-reference.git#da674e26c551b14d918e98e092430631ac7e1682`

### 本地开发安装

把仓库克隆到本地后，在「添加插件」里填**克隆后的目录路径**即可（`link:` 方式，改代码即生效）。

### 插件市场（可选，需先开启 Pages）

在 插件 → 实验性插件 → 打开 **自定义插件市场** 后，在 **Discover** 里添加索引地址：

```
https://lwfjyjy.github.io/dsh-sidebar-copy-file-reference/index.json
```

> ⚠️ 该索引需要仓库先开启 GitHub Pages（Settings → Pages → main 分支 `/docs` 目录）。

## 使用

1. 在右侧文件预览打开一个**代码文件**（如 `.java`、`.xml`）
2. **单击某行**，或**拖选多行**
3. 代码右上角出现工具栏，点复制图标或左箭头图标
4. 粘贴到对话输入框即可使用

## 兼容性

- DSH `>=0.2.1-rc.5`
- Node `>=24`
- 图标形变动画已内置 [morphicons](https://morphicons.com)（MIT），**无需额外安装依赖**
- 仅对**代码高亮可打开**的文本文件生效（图片、PDF 等不适用）

## 常见问题

- **工具栏不出现**：确认插件已「启用」，并重启过应用；且操作的是右侧文件预览里的代码。
- **安装后没生效**：完全退出应用再打开，而不是只刷新页面。
- **更新插件**：先在插件页卸载，再按上面的步骤重新安装（DSH 暂不支持原地升级）。
